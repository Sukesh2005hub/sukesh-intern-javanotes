# Git Workflow Practice – Internship Learning

This repository contains my hands-on practice of Git and GitHub workflows during my internship journey.

## 📌 Objective

To understand and implement real-world version control workflows including branching, merging, and remote repository management.

---

## 🚀 Tasks Performed

- Initialized a local Git repository
- Configured global username and email
- Connected local repository to GitHub (remote origin)
- Resolved SSH authentication issue and switched to HTTPS
- Created and managed branches:
  - main
  - master
  - dev
- Switched between branches
- Merged `dev` branch into `master`
- Used `git log` to track commit history
- Practiced `git stash` and `git stash pop`
- Pulled updates from remote branches
- Pushed changes to GitHub

---

## 🌿 Branch Workflow Practiced

- Created a feature branch (`dev`)
- Made changes in `dev`
- Pushed `dev` to GitHub
- Merged `dev` → `master`
- Updated remote repository

---

## 💡 Key Learnings

- Git does not automatically mix branches.
- Fetch and Pull serve different purposes.
- Being on the correct branch is crucial to view and manage changes.
- Proper commit tracking helps in understanding project evolution.
- Branching simulates real-world team collaboration.
